## How to upload to GitHub (about 5 minutes)
1. Unzip this folder on your computer.
2. Go to https://github.com/dantejoel369/dantejoel369.github.io
3. Click **Add file > Upload files**.
4. Drag in **everything** from the unzipped folder, including the `css` folder. Files with the same name will be replaced.
5. Type a message such as "Client-ready redesign" and click **Commit changes**.
6. Wait 1–2 minutes, then open https://dantejoel369.github.io and refresh (Ctrl+F5).
